# Tokio Hotel - Startanleitung

## Backend starten
1. Öffne ein Terminal und wechsle in das Backend-Verzeichnis:

```bash
cd backend
```

2. Backend mit Maven Wrapper starten

```bash
./mvnw spring-boot:run
```

## Frontend starten
1. Öffne ein Terminal und wechsle in das Frontend-Verzeichnis:

```bash
cd frontend
```

2. Abhängigkeiten installieren:

```bash
npm install
```

3) Development-Server starten:

```bash
npm run dev
```

Vite startet standardmäßig auf Port 5173 (z. B. http://localhost:5173).
